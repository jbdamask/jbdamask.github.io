# Company Shorts

A single-page web tool that generates research summaries about companies using the Perplexity AI API.

## Purpose

Enter a company URL and get a detailed research report including:
- Business Model and Services
- Company Growth
- Corporate Partnerships and Notable Customers
- Market Position
- References

## Setup

1. Open `company-shorts.html` in a web browser
2. Click **Settings** to expand the configuration panel
3. Enter your Perplexity API key and click the save icon
4. Select your preferred model:
   - `sonar` - Fast, basic research
   - `sonar-pro` - More detailed analysis
   - `sonar-deep-research` - Most comprehensive research

## Getting a Perplexity API Key

1. Go to https://www.perplexity.ai/account/api/group
2. Create an API key
3. Copy and paste it into the Settings panel

## Usage

1. Enter a company URL (e.g., `anthropic.com` or `https://www.anthropic.com`)
2. Click **Research**
3. Wait for the report to generate
4. Use **Copy** to copy the markdown to clipboard, or **Save** to download as a `.md` file

## Requirements

- Modern web browser with JavaScript enabled
- Perplexity API key with available credits
- Internet connection
