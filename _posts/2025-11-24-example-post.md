This is an example blog post showing you how to create content on your Jekyll site.

## How to Create Posts

Simply create a file in the `_posts/` directory with the format `YYYY-MM-DD-title.md` and add front matter at the top.

## Markdown Support

You can use all standard markdown features:

- **Bold text**
- *Italic text*
- [Links](https://example.com)
- `Code snippets`

### Code Blocks

```python
def hello_world():
    print("Hello, world!")
```

## Images

To add images, place them in `assets/images/` and reference them:

```markdown
![Alt text](/assets/images/your-image.jpg)
```

That's it! Just commit and push, and your post will appear in the feed.
